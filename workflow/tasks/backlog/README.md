# Backlog

Questa cartella contiene task validi ma non attivi nella milestone corrente.

I task dominio, content o editoriali restano qui finche la piattaforma core
plugin-first non ha specifiche sufficientemente stabili.

## Regola

- `todo`: task della milestone attiva o immediatamente lavorabili
- `backlog`: task da rivalutare dopo la chiusura delle specifiche core
- `in-progress`: task in lavorazione
- `done`: task chiusi

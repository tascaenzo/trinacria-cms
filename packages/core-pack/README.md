# @trinacria-cms/core-pack

Official baseline plugin pack for Trinacria CMS.

`core-pack` is a regular kernel plugin that provides default CMS capabilities:

- users
- roles
- permissions
- workspaces
- settings

Current status:

- package scaffold completed
- plugin manifest and module graph placeholders in place
- domain implementations will be added incrementally

## Scripts

```bash
npm run dev -w @trinacria-cms/core-pack
npm run build -w @trinacria-cms/core-pack
npm run typecheck -w @trinacria-cms/core-pack
```

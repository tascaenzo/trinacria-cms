# JsonView

`JsonView` fornisce un albero JSON ispezionabile per payload runtime, debug e configurazioni.
Supporta espansione/collasso dei nodi e copia del payload formattato. Nei flussi admin
preferire `JsonViewDialog` o un trigger dedicato, evitando viste JSON inline nelle pagine.

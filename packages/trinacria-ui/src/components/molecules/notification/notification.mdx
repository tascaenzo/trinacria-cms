# Notification

Messaggio dismissable con superfici semantiche dedicate: azzurro chiaro per
informazioni, verde chiaro per successi, giallo chiaro per avvisi e rosso chiaro
per errori. I token delle notifiche sono separati da badge e feedback inline per
mantenere il componente riconoscibile sopra il canvas.
